# GreenTrails - Local Eco-Tourism & Travel Guide

A regional travel website built with HTML, CSS, JavaScript, and Bootstrap 5. It promotes eco-friendly tourism, local businesses, and sustainable travel across Kenya.

---

## About This Project

GreenTrails helps travelers find eco-friendly destinations, green accommodations, and ready-made itineraries across Kenya. It also features a travel blog with sustainable travel tips, a booking form, and a full FAQ section. Built as a front-end development assignment.

- **Built with:** HTML5, CSS3, JavaScript (ES6+), Bootstrap 5
- **Pages:** 9 pages
- **Theme:** Local Eco-Tourism & Travel Guide
- **Start date:** 15 June 2026
- **Deadline:** 28 June 2026

## Pages

| Page | File | What it does |
|---|---|---|
| Home | index.html | Hero carousel, stats, featured destinations, testimonials, CTA |
| Destinations | destinations.html | Grid of Kenyan eco-friendly travel spots with live search and region filter |
| Eco-Accommodations | stays.html | Directory of green hotels, lodges and campsites with type and price filter |
| Itineraries | itineraries.html | Day-by-day travel plans with eco-impact summaries and Bootstrap accordions |
| Travel Blog | blog.html | Articles on sustainable packing, wildlife, and community travel |
| About Us | about.html | Mission, core values, team bios, and Why Travel Green section |
| Contact & Booking | contact.html | Booking inquiry form with real-time JavaScript validation |
| FAQ | faq.html | 10 common questions answered using Bootstrap accordion |
| 404 | 404.html | Custom error page with navigation back to home |

---

## JavaScript Features

| Feature | Page | Description |
|---|---|---|
| Live search + region filter | destinations.html | Filters destination cards instantly as user types or clicks region |
| Type + price filter | stays.html | Filters accommodation cards by type and KSh price range |
| Blog search | blog.html | Filters blog articles by title in real time |
| Contact form validation | contact.html | Validates name, email, phone, inquiry type and message with inline errors |
| Dark / Light mode toggle | All pages | Saves preference to localStorage, applies on every page load |
| Scroll to top button | All pages | Appears after scrolling 300px, smooth scrolls back to top |
| Active nav highlight | All pages | Reads current URL and marks the correct nav link as active |
| Fade-in on scroll | index.html, about.html | IntersectionObserver fades sections in as user scrolls down |
| Bootstrap tooltips | index.html | Tooltips appear on quick access buttons |
